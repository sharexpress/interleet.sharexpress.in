# Rule 01 — Design Philosophy & Core Principles

> "Perfection is achieved, not when there is nothing more to add, but when there is nothing left to take away." — Antoine de Saint-Exupéry

Interleet is a high-performance developer tool, not an entertainment app or marketing landing page. Every interface element must serve engineers solving complex technical problems.

---

## The Five Cardinal Laws

### 1. Function First, Decoration Never
- Every pixel on screen must help the user write code, evaluate system architecture, or read specifications faster.
- Decorative gradients, frosted glass effects, artificial drop shadows, and visual filler must be removed.
- If an element can be removed without reducing user comprehension or speed, **it must be removed**.

### 2. Density with Clarity
- Take direct inspiration from LeetCode and GitHub: dense tables, tightly packed problem lists, compact filter bars, and clear structural hierarchy.
- Density is not clutter. Clutter is redundant borders, nested cards, and useless icons. Density is clean rows with clear typography, consistent column widths, and immediate scannability.

### 3. Silence Over Noise
- The product speaks through clean structure, not visual shouting.
- Banned: "New!" badges, "Trending 🔥" tags, exclamation marks, pulsing glows, and celebratory confetti.
- Engineering tools earn trust through calm, quiet reliability.

### 4. Consistency Beats Novelty
- One button system. One card structure. One spacing grid. One type scale.
- An engineer should never encounter a different table layout, custom modal, or non-standard button styling when switching between Algorithms, Databases, System Design, or Contests.

### 5. Zero AI-Generated Aesthetic Slop
- The most common failure mode in modern frontend development is the "AI vibe": purple-to-blue hero gradients, oversized 24px rounded corners, emoji icons, and floating card soup with massive drop shadows.
- Actively design against this aesthetic. Use structured, restrained, near-black dark surfaces with razor-sharp 1px dividers and disciplined typography.
