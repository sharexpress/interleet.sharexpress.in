# Rule 07 — Content & Microcopy Rules

Engineers value precision and conciseness. Microcopy must respect the developer's intelligence and time.

---

## 1. Sentence Case Everywhere

- Use standard sentence case for all headings, buttons, tab labels, table headers, and messages:
  - ✅ "Run code", "Solve challenge", "Submit solution", "Test case results", "Table schema"
  - ❌ "Run Code", "Solve Challenge", "SUBMIT SOLUTION", "Test Case Results"
- Capitalize only proper nouns, acronyms, and recognized technologies (e.g. SQL, Python, Docker, PostgreSQL, REST).

---

## 2. Zero Exclamation Marks

- Exclamation marks in system copy scream at the user and feel unprofessional.
  - ✅ "All test cases passed"
  - ❌ "All test cases passed!"
  - ✅ "Connection restored"
  - ❌ "Connection restored!"
  - ✅ "Challenge completed"
  - ❌ "Congratulations! You crushed it! 🎉"

---

## 3. Tool-First Tone (Zero Marketing Hype Inside Product)

- Authenticated product pages are tools for working engineers, not sales landing pages.
- **Banned Marketing Phrases**:
  - ❌ "Supercharge your coding skills!"
  - ❌ "Level up your interview prep today"
  - ❌ "Trending challenges 🔥"
  - ❌ "World-class engineering sandbox"
- **Approved Professional Phrasing**:
  - ✅ "Practice system architecture and multi-domain problem solving."
  - ✅ "53 database challenges available across PostgreSQL, MySQL, and SQLite."
  - ✅ "Recent submissions"

---

## 4. Actionable Error Messages

Every error message must answer two questions:
1. **What happened?**
2. **What should the user do next?**

- ❌ "Something went wrong. Please try again."
- ✅ "Execution timed out after 5.0 seconds. Check for infinite loops or non-terminating queries."
- ❌ "Invalid input format."
- ✅ "JSON parsing failed on line 12: expected comma before property."
